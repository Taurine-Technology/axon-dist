Ubuntu and Debian: APT rollout

APT is pending publication. The bootstrap returned HTTP 404 on 9 September 2026. Configuring signing secrets or merging documentation does not publish packages. Confirm the bootstrap and signed metadata for your channel are available before using the commands below.

The planned repository base is https://dist.taurinetech.com/pulse/apt, with bootstrap install-apt.sh. The default channel is main. Desktop packages target Ubuntu 24.04 LTS or compatible newer systems on amd64 and arm64. Debian desktop compatibility requires verifying the available GTK 4 and WebKitGTK 6 packages and their ABI versions; it is not yet validated. The headless package has no GUI dependencies. After a verified release publishes these files:

curl -fL https://dist.taurinetech.com/pulse/apt/install-apt.sh -o install-apt.sh
# Inspect the script before running it.
sh install-apt.sh --channel main --package desktop

Desktop installs use axon-pulse-desktop. Headless servers use --package headless to install axon-pulse; use the controller's claim page or sensor UI to obtain the enrollment command, for Ubuntu/Debian. It uses this APT bootstrap and passes the claim token through standard input. Other Linux systems require the portable/manual installer. Keep enrollment tokens out of public download URLs.

For a preview, explicitly select --channel alpha or --channel beta. Optional automatic installation uses --enable-auto-updates and is supported only on main. Without that opt-in, apply updates with Ubuntu's package tools:

sudo apt update
sudo apt install --only-upgrade axon-pulse-desktop
# For a headless installation, use axon-pulse instead.

Downloading a .deb alone does not configure a repository for future updates. The bootstrap establishes that package source. APT publication belongs to axon-pulse's static distribution pipeline; this archive does not publish a separate repository.

Portable AppImage alternative

AppImage remains available for Linux users who prefer a portable desktop application. Select the AppImage matching your architecture from the current channel's release index, save it in a permanent location, make it executable, and run it. For example:

chmod +x ~/Applications/axon-pulse_linux_amd64.AppImage
~/Applications/axon-pulse_linux_amd64.AppImage

Keep the file writable by your user for its built-in updater. AppImage is separate from APT package management; desktop menu and browser claim-link integration may require additional setup. See the AppImage guide. For Ubuntu/Debian managed installations, prefer the APT route once published.
